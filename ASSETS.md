# MathWar — Asset Map

Semua aset yang sebelumnya tertanam sebagai Base64 di `index.html` sekarang dipisahkan ke folder `assets/`, sehingga mudah diganti tanpa menyentuh kode JavaScript.

- `assets/playerIdle.png` — sprite idle pemain
- `assets/playerAttack.png` — sprite serangan pemain
- `assets/playerHurt.png` — sprite terkena serangan pemain
- `assets/playerDead.png` — sprite mati pemain
- `assets/enemyIdle.png` — sprite idle musuh
- `assets/enemyAttack.png` — sprite serangan musuh
- `assets/enemyHurt.png` — sprite terkena serangan musuh
- `assets/enemyDead.png` — sprite mati musuh
- `assets/bg.jpg` — background arena
- `assets/slash.png` — efek tebasan
- `assets/sfxAtkPlayer.mp3`, `sfxAtkEnemy.mp3`, `sfxHit.mp3`, `sfxVictory.mp3`, `sfxGameOver.mp3` — efek suara
- `assets/logo/math-quest-logo.png` — logo utama transparan untuk menu
- `assets/logo/crest.png` — bagian lambang/ksatria
- `assets/logo/wordmark.png` — bagian tulisan/logo bawah
- `assets/logo/source-original.jpg` — file logo asli yang diberikan

Untuk mengganti logo utama, cukup ganti `assets/logo/math-quest-logo.png` dengan gambar baru berukuran/proporsi serupa.
